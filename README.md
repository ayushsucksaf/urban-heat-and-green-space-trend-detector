# Pune Vegetation Change Detector

NASA Space Apps Challenge 2026, Earth System Trend Detective.

A small web map that shows where Pune lost vegetation between 2000 and 2024, using NASA MODIS satellite data. The district as a whole got greener over that period, but a cluster of cells in east Pune (the Kharadi-Manjri corridor) lost roughly 36 to 39 percent of their pre-monsoon vegetation.

Live demo: [DEMO](https://ayushsucksaf.github.io/urban-heat-and-green-space-trend-detector/)

## What it does

- Full-screen map of the NDVI trend (change in vegetation per decade) for Pune district, 1 km resolution.
- Hover anywhere to read the trend at that spot.
- Time series of district-mean NDVI, 2000 to 2024.
- List of the top urban hotspots. Click one to zoom to it.
- Dark and satellite basemaps, plus an opacity slider for the overlay.

No login, no API keys, no backend. It is a static page.

## Data

- NASA MODIS Terra MOD13A3 v061, monthly 1 km NDVI, 2000 to 2024 (March to May only).
- NASA GPM IMERG Monthly V07, March to May rainfall, included in `data/timeseries.csv` as a sanity check. It is not shown in the app.
- Processing was done in Google Earth Engine.
- Basemaps: Esri (dark gray canvas, World Imagery) and OpenStreetMap contributors, for context only.

## How it works

1. For each year, take the March to May mean NDVI per 1 km pixel.
2. Fit a straight line through the 25 yearly values per pixel. The slope is the NDVI change per decade. That is the map layer.
3. Aggregate to 1 km cells, express change as a percent of the 2000 to 2004 baseline, and rank the cells.
4. Cells within 15 km of central Pune count as urban. The rest are left out of the headline because they are farmland or hill country, not the city.

Full details are in `methodology.md`.

## What we left out

We also ran land surface temperature (MODIS MOD11A2). It showed cooling across almost the whole district, which does not make sense for an expanding city, and we could not work out why in the time we had. So we are not reporting it. The app says temperature is under review. More in `methodology.md`.

## Limitations

- 1 km pixels are not neighborhoods. Cell names are approximate.
- NDVI loss is not the same as construction. Farmland changes can look similar. We have not confirmed the cause cell by cell.
- The trend test is a basic linear regression and ignores year-to-year correlation.
- Rainfall differs a lot between years and affects NDVI. We did not control for it.

## Run it locally

Needs Python 3 for the data step only.

```
python -m pip install -r requirements.txt
python scripts/prepare_data.py
cd docs
python -m http.server 8000
```

Then open http://localhost:8000.

`prepare_data.py` reads the files in `data/` and writes `docs/data.js`, which the page loads. Re-run it if you change the data.
